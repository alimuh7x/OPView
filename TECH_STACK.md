# Tech Stack

This project is a VTK 2D slice viewer built with Python and Dash, visualising VTK data in a web browser.

## Stack overview

- **Language / runtime:** Python 3.12–3.13 (CPython)
- **Frontend (browser):** HTML / CSS / JS generated by Dash
- **Web framework / UI:** `dash`, `dash-mantine-components`, `plotly`
- **Data & numerics:** `numpy`, `scipy`, `pyvista`, `vtk`
- **Other libraries:** `markdown`, `kaleido`
- **Data source:** VTK files (e.g. `VTK/*.vts`)

## Flowchart

```mermaid
flowchart TD
  U[User] --> T[Run setup.sh and python app]

  T --> D[Start Dash app OPView]
  D --> C[Create tab configs for datasets]
  D --> VP[Create ViewerPanel for each tab]

  VP --> S[Read user inputs from controls]
  VP --> R[Use VTKReader to load data]
  R --> F[Read VTK files from VTK folder]
  R --> G[Compute slice grid and statistics]
  G --> VP

  VP --> P[Build Plotly heatmap figure]
  P --> B[Send HTML CSS JS to browser]
  B --> U

  U --> B
  B --> VP
```
